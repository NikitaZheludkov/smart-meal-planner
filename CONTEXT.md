# 🍎 SMART MEAL PLANNER — КОНЦЕПЦИЯ ПРОЕКТА

## 1. Суть Проекта
**Smart Meal Planner** — коммерческий инструмент для управления питанием и покупками в Telegram (Mini App).
**Задача:** Полная автоматизация процесса "От идеи блюда до покупки продуктов".
**Принцип:** Пользователь не должен тратить время на составление списков вручную. Система делает это за него.

## 2. Ключевой Функционал
1.  **Планирование:** Гибкий календарь (Drag & Drop) для составления меню на любой период.
2.  **Авто-Список:** Список покупок генерируется автоматически на основе блюд в Плане.
3.  **Синхронизация (Multi-access):**
    * Данные мгновенно обновляются на всех устройствах.
    * Возможность совместного доступа: изменения, внесенные одним пользователем, сразу видны другим участникам группы (если они добавлены).

## 3. Логика работы (User Flow)
1.  **База:** Есть продукты (кирпичики) -> Из них собираются Блюда.
2.  **План:** Блюда ставятся в сетку календаря.
3.  **Покупки:** Ингредиенты из плана попадают в "Список покупок".
4.  **Действие:** Пользователь в магазине отмечает купленное -> Список обновляется.

## 4. Технические Принципы (Для ИИ)
* **Архитектура данных:**
    * Используем модель **Workspace/Group** (технически `group_id` или `household_id`).
    * Все данные (планы, рецепты, списки) привязаны к этой Группе.
    * В группе может быть как 1 пользователь, так и несколько. Для базы данных это не имеет значения.
* **Платформа:** Telegram Web App. Интерфейс нативный (iOS-like), быстрый, без перезагрузок.
* **Vibecoding:**
    * Структура БД не фиксирована жестко.
    * Ты (ИИ) предлагаешь архитектурные решения (таблицы, связи) по мере реализации функций.
    * Главное требование к коду: модульность и расширяемость для будущей коммерческой эксплуатации.

## 5. Текущий статус
Разработка MVP.
Фокус на базовой механике: **Создание блюда -> Добавление в план -> Генерация списка.**
